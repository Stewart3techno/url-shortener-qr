# 🔗 URL Shortener & QR Code Generator

A lightweight Python command-line utility that shortens long web links and generates downloadable QR codes.

## 🛠️ Features
- Fast URL shortening powered by TinyURL API.
- Automatic QR code image generation (`.png`).
- Zero API key setup required.
